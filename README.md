# IT23217140 - Assignment 1 (Option 1)

This repository contains the automation script and test case file for IT3040 Assignment 1 (Option 1: Chat Singlish to Sinhala transliteration testing).

## Files

- `IT23217140_test_automation.py` - Playwright automation script
- `IT23217140 _Test cases.xlsx` - Completed test case sheet
- `IT23217140.txt.txt` - Git repository link text file

## Prerequisites

- Python 3.11+ (tested with Python 3.13)
- Google Chrome (or Playwright Chromium)
- Python packages:
  - `playwright`
  - `openpyxl`

## Setup

Install dependencies:

```bash
pip install playwright openpyxl
playwright install
```

## Run Automation

From this folder, run:

```bash
python -u "IT23217140_test_automation.py" --url "https://www.pixelssuite.com/chat-translator" --excel "C:\Users\Tashini\Desktop\ASS1\IT23217140\IT23217140 _Test cases.xlsx" --sheet "Test cases" --header-row 1 --input-col "Input" --expected-col "Expected output" --actual-col "Actual output" --status-col "Status" --wait-ms 6000 --retries 10 --retry-wait-ms 900 --type-delay-ms 50 --save-every 1 --headless
```

## Notes

- Keep the Excel file closed while running the script so results can be saved.
- `Actual output` and `Status` are generated by the script.
- `Singlish input types covered` and `Evidence or rationale for the input type covered` are filled manually.
